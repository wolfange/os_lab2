# Лабораторная работа: Межпроцессное взаимодействие (Pipes)

Программа демонстрирует взаимодействие между родительским и дочерним процессами в ОС Linux с использованием системных вызовов `fork`, `pipe`, `dup2` и `execl`. 

Родительский процесс считывает строки с числами с клавиатуры и передает их через неименованный канал (pipe) дочернему процессу. Дочерний процесс последовательно делит первое число строки на все последующие и записывает отформатированный результат в указанный текстовый файл. Предусмотрена обработка ошибки деления на ноль.

## Структура проекта
Исходя из текущего дерева директорий[cite: 4]:
* `src/` — исходный код программы:
  * `parent.c` — родительский процесс (обработка ввода пользователя и передача данных в канал)[cite: 4].
  * `child.c` — дочерний процесс (парсинг строк, вычисления, запись логов в файл)[cite: 4].
* `report/` — директория для отчета по лабораторной работе[cite: 4].
* `Makefile` — скрипт для автоматической компиляции[cite: 4].
* `README.md` — описание проекта[cite: 4].

## Сборка и запуск

1. **Компиляция проекта:**
    ```bash
    make
    ```
2. **Запуск программы:**
    ```bash
    ./parent
    ```
3. **Удаление исполняемых файлов:**
    ```bash
    make clean
    ```
